족보 사진 판독

족보책을 사진으로 찍어 올리면 한자 이름, 세대, 생몰일, 字·號·墓 기록을 읽어 칸마다 채워 줍니다. 판독 모델은 PC 안에서 동작합니다.

족보책을 한 장씩 손으로 옮겨 적는 일은 시간이 많이 듭니다. 우리의 족보는 족보 쪽을 찍은 사진을 읽어 인물 기록 칸을 채워 줍니다.

무엇을 읽나요

  • 한자 이름과 세대(世)
  • 생년·졸년과 생몰일
  • 字·初名·號, 배위(配), 묘소(墓) 기록

판독 순서

  1. 족보 쪽을 밝은 곳에서 정면으로 찍습니다. 글자가 기울거나 그림자가 지지 않게 하면 더 잘 읽습니다.
  2. 프로그램의 족보 이미지 판독에서 사진을 올립니다.
  3. 읽은 결과가 원본 사진 옆에 칸별로 나옵니다. 원본과 나란히 보며 틀린 글자를 고칩니다.
  4. 확인이 끝나면 한꺼번에 등록합니다.

정확도와 개인정보

판독 모델은 번체·간체 한자를 함께 배웠으며 내 PC 안에서 동작합니다. 사진은 서버로 보내지 않습니다. 오래된 목판 인쇄는 획이 뭉개져 비슷한 글자로 읽힐 수 있으므로, 판독 결과는 참고용으로 보고 원본과 대조해 확정하십시오.

원하면 본인의 Anthropic API 키로 Claude 판독을 한 번 더 돌려 정밀하게 읽을 수 있습니다. 이 선택 기능을 쓸 때만 해당 사진이 Anthropic으로 전송되며, 사용료는 Anthropic에 따로 냅니다.
