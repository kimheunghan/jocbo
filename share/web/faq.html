자주 묻는 질문

우리의 족보 족보 프로그램의 설치, 무료판 20명 제한, 정식판 구매와 PC 이동, 판독 정확도, 웹 공유, 환불에 관한 질문과 답.

설치와 실행

어디서 받나요?

Microsoft Store에서 무료로 받습니다. Store를 쓸 수 없는 PC는 홈페이지의 설치 파일(.exe) 직접 받기를 씁니다.

설치했는데 바탕화면에 아이콘이 없습니다.

Store 앱은 시작 메뉴에 등록됩니다. 시작 메뉴에서 "족보"를 검색해 실행하고, 원하면 바탕화면으로 끌어다 놓거나 작업 표시줄에 고정하십시오.

맥(Mac)에서도 되나요?

지금은 Windows 10·11만 지원합니다. 공유 링크는 맥과 휴대폰 브라우저에서도 열립니다.

무료판과 정식판

20명은 어떻게 세나요?

한 계정의 모든 족보에 등록한 인물 수를 합친 것입니다. 20명이 되면 새로 등록하는 것만 막히고, 이미 있는 기록을 보고 고치고 인쇄하는 것은 그대로 됩니다.

정식판은 얼마이고 어떻게 등록하나요?

한 번 구매로 ₩29,000(부가세 포함)입니다. 결제하면 라이선스 키가 결제 화면과 이메일로 오며, 프로그램의 정식판 전환 창에 붙여 넣으면 바로 인원 제한이 풀립니다. 등록할 때는 인터넷 연결이 필요합니다.

다른 PC로 옮길 수 있나요?

키 하나로 PC 2대까지 씁니다. 옮길 때는 쓰지 않을 PC에서 등록을 풀고 새 PC에 키를 넣으면 됩니다.

환불은 어떻게 하나요?

구매 후 14일 안에 결제 확인 이메일에 회신하거나 문의 메일로 알려 주시면 환불해 드립니다. 자세한 내용은 환불 정책을 보십시오.

기록과 판독

판독이 100% 정확한가요?

아닙니다. 오래된 목판 인쇄는 획이 뭉개져 비슷한 글자로 읽히기도 합니다. 판독 결과는 원본 사진과 나란히 보며 고친 뒤 등록하는 방식입니다. 족보 사진 판독 안내를 참고하십시오.

내 족보 기록은 어디에 저장되나요?

설치한 PC 안에 저장되며 서버로 보내지 않습니다. 웹 공유를 시작한 족보만 사본이 공유 사이트에 올라갑니다. 자세한 내용은 개인정보처리방침을 보십시오.

공유

웹 공유 링크는 PC를 꺼도 열리나요?

열립니다. 공유 사이트에 사본이 보관됩니다. PC에서 고친 내용은 프로그램이 켜져 있을 때 몇 초 뒤 자동으로 반영되고, 꺼져 있던 동안 고친 것은 다음에 켤 때 올라갑니다.
