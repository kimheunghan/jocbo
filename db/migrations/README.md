# 마이그레이션

`001_initial.sql`은 PostgreSQL 초기 스키마입니다. 빈 DB에 한 번만 적용합니다.
`db/schema.sql`은 같은 초기 스키마의 기준 파일입니다. 둘 중 하나만 실행하세요.

후속 변경은 `002_설명.sql`처럼 새 파일로 추가하고, 적용 전 백업 후 실행 내역을 기록하세요. 현재 자동 마이그레이션 도구는 사용하지 않습니다. 앱의 `create_all`은 없는 테이블만 생성하며 기존 테이블의 열 변경은 처리하지 않습니다.

`003_person_bon_gwan.sql`는 `persons`에 본관 열을 추가합니다. 족보책은 배우자를 `配天安全氏京愛`처럼 본관·성씨·이름 순으로 적으므로 이 값이 있어야 원본 표기를 재현합니다. SQLite는 앱 시작 시 자동으로 열을 추가합니다.
